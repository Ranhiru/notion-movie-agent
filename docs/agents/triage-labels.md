# Triage labels

| Role | Status value |
| --- | --- |
| Needs evaluation | needs-triage |
| Needs more information | needs-info |
| Ready for agent implementation | ready-for-agent |
| Requires human implementation | ready-for-human |
| Will not be actioned | wontfix |

Record the corresponding value in the issue's `Status:` line.
Wayfinding's claimed/resolved values describe its separate work lifecycle.
